# 😂 Random Programming Entertainment

A simple and interactive web application that displays random programming memes, jokes, inspirational quotes, and riddles. Built using **HTML**, **CSS**, and **Vanilla JavaScript**, this project demonstrates DOM manipulation, event handling, random data selection, and dynamic content rendering without using any frameworks. ## 🚀 Features

- 🖼️ Display a random programming meme
- 😂 Show a random programming joke
- 💡 Generate an inspirational programming quote
- 🧩 Display a random riddle
- 👀 Reveal the answer to the current riddle
- 🧹 Automatically clears previous content before showing new content
- 📱 Simple responsive two-column layout

## 📖 How It Works

Each button triggers a JavaScript function that:

1. Clears the currently displayed content.
2. Randomly selects an item from a predefined array.
3. Dynamically creates HTML elements.
4. Inserts the new content into the page.

For riddles, the answer remains hidden until the **Reveal Riddle Answer** button is clicked.
